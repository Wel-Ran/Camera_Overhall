# **Camera Overhaul**
A lightweight mod that allows you to set up a camera surveillance network using custom player heads.
# **Usage**
1. Take a player head and rename it on an anvil starting with "Monitor:" followed by any name (e.g., Monitor: Test).
2. Place this monitor head anywhere you like.
3. Create a camera head by naming it starting with "Camera:", followed by the exact name of your monitor, and ending with a number from 1 to 16 (e.g., Camera: Test 1).
4. Place the camera heads wherever you want to watch from.
5. Once the cameras are placed, right-click the Monitor to open the interface and switch between them.
# **Interface**
-Top: Two navigation buttons flanking the active camera display for sequential switching (next/previous).

-Right: A button that opens a full drop-down list of all connected cameras for direct switching.

-Bottom Left: Displays the active network name, along with the current date and local time.

-There are buttons in the bottom center to change the camera rotation and a return button between them
